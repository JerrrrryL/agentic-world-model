## 3. Harness / agent interface

**Chain** [VERIFIED]: `bash src/commit_utils/commit.sh` (sweep) → `condor_submit_bid <bid> -a "agent=..." -a "agent_config=..." -a "eval=..." -a "model_to_train=..." -a "num_hours=10" src/commit_utils/single_task.sub` → `bash src/run_task.sh $(eval) $(agent) $(model_to_train) $(Cluster) $(num_hours) $(agent_config) $(num_gpus)`. `condor_submit_bid` is MPI-IS-specific; README: "we only support the HTCondor job scheduler". `run_task.sh` is plain bash and could run on any GPU node with `.env`, Apptainer, fuse-overlayfs, `uuidgen`, `tree`, `nvidia-smi` (UNVERIFIED — not exercised).

**`run_task.sh` pipeline** [VERIFIED]: build job dir → judge OAuth precheck (curl `chatgpt.com/backend-api/codex/models` with the token in `agents/codex_non_api/auth.json`; `exit 1` if missing or non-200, before the agent runs) → agent:

```

apptainer exec --nv -c --cleanenv --pid --no-init \
  --env PATH=... --env HF_HOME=/home/ben/hf_cache <allowlisted --env KEY=..> \
  --env VLLM_API_KEY=inspectai --env PYTHONNOUSERSITE=1 --env NUM_GPUS=.. --env PROMPT=".." --env AGENT_CONFIG=".." \

  --home $JOB_DIR:/home/ben --pwd /home/ben/task --writable-tmpfs $CONTAINERS_DIR/standard.sif \
  bash -c "{ python check_cuda.py && python check_cuda_writing.py || exit 1; bash system_monitor.sh & ...; bash agent_solve.sh; ...; } 2>&1 | python timestamp_lines.py" > $EVAL_DIR/solve_out.txt
```

## 6. Complications for running it ourselves

- **Hardware/OS** [VERIFIED]: exactly N× NVIDIA H100 80GB per job (`check_cuda.py` string-matches "H100" and requires an idle GPU; HTCondor requirement `NVIDIA H100 80GB HBM3`); 128 GB RAM, 16 CPUs, 400 GB scratch; rootless Apptainer + `fuse-overlayfs`/`fusermount` on the host; MPI-IS specifics (`condor_submit_bid`, `module load cuda/12.1` in `set_env_vars.sh` under `htcondor_mpi-is`, hostnames in `.sub`, `/fast/...` paths, `/home/ben` hard-coded as sandbox home).
- **Credentials** [VERIFIED]: `.env` (from `example.env`) — `OPENAI_API_KEY` (arenahardwriting/healthbench grading with `gpt-5-mini`; also `CODEX_API_KEY` for API Codex agents), `ANTHROPIC_API_KEY` or `claude setup-token` OAuth token (`agents/claude_non_api/oauth_token`), `GEMINI_API_KEY`, `OPENCODE_API_KEY`, `OPENROUTER_API_KEY`, `GLMX_API_KEY`, `KIMI_API_KEY`, `MY_HF_TOKEN` (gated `Idavidrein/gpqa`; gemma also gated). **Independent of agent choice: a ChatGPT-Pro subscription `agents/codex_non_api/auth.json`** — `run_task.sh` exits at "JUDGE AUTH CHECK" before the agent runs otherwise, and all judges run on it (`judge_lib.sh` forces `forced_login_method = "chatgpt"`, blanks `CODEX_API_KEY`). Retargeting judges = editing `run_judge_exec` in `src/judges/judge_lib.sh` + the precheck in `run_task.sh` (the Harbor adapter's verifier already uses an API key with `gpt-5.1-codex`).
- **Pre-downloads** [VERIFIED]: `bash containers/download_hf_cache/download_hf_cache.sh` (14 models incl. 7B/14B checkpoints + ~150 datasets from `resources.json`; hundreds of GB — size UNVERIFIED) and `bash src/judges/test_data_download/download_test_data.sh` for all 7 `test_data.json` (AIME `math-ai/aime25`, Arena-Hard from GitHub, BFCL `BFCL_v3_exec_simple.json`, GPQA gated, GSM8K, HealthBench Azure blob, HumanEval) — hard-required by `run_task.sh:136`.
- **Cost**: 10 H100-h per task → 280 GPU-h per 28-task sweep (paper: ~$840 at $2.5–3/h) [VERIFIED]. Agent API per single task observed: $17.26 (Opus 4.8, gsm8k/Qwen3-1.7B) and $33.33 (Opus 4.6, gsm8k/gemma) [VERIFIED]; paper's Qwen3 Max ~$910, Opus 4.6 $600–750, Gemini $225–310, Codex <$35 are consistent with per-sweep totals (interpretation UNVERIFIED). Plus 4 Codex-xhigh judge passes per run and `gpt-5-mini` grading on 2 benchmarks (also during the agent's own dev evals).
- **Reproducibility** [VERIFIED]: `src/utils/update_agent_cli.sh` npm-installs the CLI `@latest` at every run unless `POST_TRAIN_BENCH_SKIP_CLI_UPDATE=1` (`cli_version.txt` records what ran); eval image (`vllm_debug.sif`, v1.0 label, patched inspect_ai) ≠ agent image (`standard.sif` v1.1) — issue #65 (transformers mismatch breaks final eval); one decoding sample per `metrics.json`; adding an agent to the leaderboard requires editing `HARDCODED_AGENT_MAP` in `scripts/utils.py`.
